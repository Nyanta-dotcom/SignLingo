# Báo cáo theo tuần (môn Nhập môn Trí tuệ nhân tạo)

Yêu cầu từng tuần: `docs/course/week1.docx` … `week5.docx`. Mỗi báo cáo gồm 8 mục chung (What, When, Why, Who, How much, rủi ro, thay đổi, vấn đề) và phần riêng của tuần.

| Tuần | Chủ đề riêng | File |
|---|---|---|
| 1 | SWOT, kế hoạch liên lạc, tổng quan dự án, WBS, cấu trúc GitHub | [week1.md](week1.md) |
| 2 | Định nghĩa bài toán, 3 câu hỏi nghiên cứu, khám phá và chất lượng dữ liệu | [week2.md](week2.md) |
| 3 | Tiền xử lý, chia dữ liệu, đặc trưng, lý do chọn mô hình, baseline | [week3.md](week3.md) |
| 4 | Kiến trúc, huấn luyện, chỉ số, so sánh, phân tích lỗi | [week4.md](week4.md) |
| 5 | Tích hợp cuối, demo pipeline, tổng kết, hạn chế, hướng phát triển, rà soát GitHub | [week5.md](week5.md) |

**Nguồn số liệu:** mọi con số lấy từ `ml/reports/experiments/*.json` (tổng hợp ở `ml/reports/summary.md`, `ml/reports/RESULTS.md`), `ml/reports/data_quality.json`, `ml/reports/x_pose_check.json` và file benchmark ghi từ AI Lab (docs/02). Không dùng số của báo cáo tuần 3–4 cũ.

**Ô `[nhóm điền]`:** thông tin repo không có (số giờ làm việc, ngày buổi trình bày, kênh liên lạc). Nhóm điền trước khi nộp.

Slide trình bày được làm riêng, không đưa lên GitHub.
